# Roadmap

Open directions for the study site. Each item leaves this file when it ships and becomes a version-log entry; git keeps finished plans. Every item has an issue with its plan.

## Direction

Cover the whole Autonomy Technologies degree, semester by semester, with material that makes recall and exam practice the default: guides to read and test yourself on, labs to predict and check, worked solutions to redo. Stay static, public, and free to host on GitHub Pages, with progress kept in the student's own browser.

## Now

**Track progress on worked-solution pages** (stated 2026-11-18, [#8](https://github.com/UNKNOWN-X0/Autonomy-Technologies/issues/8)). Worked solutions are the main exam preparation, yet nothing records which problems were worked through, and spaced review ignores them. *Done when* each problem can be marked worked through or to redo, the hub shows a count per exercise page, and redo marks feed the review list.

**Clear the open design-hook findings** (stated 2026-11-19, [#11](https://github.com/UNKNOWN-X0/Autonomy-Technologies/issues/11)). About 35 findings sit on guide and lab pages, so real problems hide among deliberate choices. *Done when* the hook reports nothing on the hub, guides, and labs, or each remaining finding is a documented exception in DESIGN.md.

## Next

**Introduction to MATLAB course material** (stated 2026-11-19, [#12](https://github.com/UNKNOWN-X0/Autonomy-Technologies/issues/12)). The only semester 1 subject without pages. Waits on a decision about when the course starts and what form suits a tool course.

**Site-wide search** (stated 2026-11-18, [#10](https://github.com/UNKNOWN-X0/Autonomy-Technologies/issues/10)). With 30+ guides and worked-solution pages, finding a definition means guessing the chapter. A search index built at authoring time keeps the site static.

**Offline use and a self-hosted font** (stated 2026-11-18, [#9](https://github.com/UNKNOWN-X0/Autonomy-Technologies/issues/9)). Quick checks on a phone with poor signal need cached pages and no Google Fonts request.

## Later

**Semester 2** (stated 2026-11-19, [#13](https://github.com/UNKNOWN-X0/Autonomy-Technologies/issues/13)). Add the next semester's subjects to the hub when the semester starts. Waits on which modules to cover.

## Not planned

**Accounts, server sync, or analytics.** Progress stays in the browser, with export and import as the backup; the site stays static and private.

**The FAU logo.** It is a protected trademark; the site is not an official FAU publication.
