# Security policy

The site is static (HTML, CSS and JavaScript on GitHub Pages). It has no server, no accounts and no database; progress is stored only in the visitor's browser.

## Supported versions

Only the live site and the `main` branch are supported. Fixes are released to the live site; old versions are not patched.

## Reporting a vulnerability

Report it privately through [GitHub's private vulnerability reporting](https://github.com/UNKNOWN-X0/Autonomy-Technologies/security/advisories/new) (Security tab → Report a vulnerability). Please do not open a public issue. Include the page, what an attacker could do, and steps to reproduce.

You can expect a first reply within a week. Once a fix is live, the advisory is published with credit to you unless you prefer otherwise.
