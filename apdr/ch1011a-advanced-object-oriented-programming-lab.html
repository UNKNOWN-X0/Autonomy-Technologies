Advanced Object-Oriented Programming Lab

Algorithms, Programming, and Data Representation · Module 23131 · Chapter 1011a

Predict what Python will share, find, bind, or create. Each experiment reveals the rule behind the result, then lets you explore the same mechanism.

How the lab works

  1. Predict. Choose an answer before the trace runs.
  2. Rate your confidence. A sure but wrong prediction marks an idea to revisit.
  3. Reveal. Follow the object or lookup trace.
  4. Explore. Open the sandbox at any time and change the rule; each completed experiment adds one lab skill.
