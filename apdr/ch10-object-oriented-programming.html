10.1 Objects and abstraction

In plain words: an object keeps related data together and offers operations for using it.

Object abstractionrepresentation + interfaceThe interface defines behaviour while hiding implementation.

Every Python value is an object with a type. Its representation may be simple or composite; its interface says how other code can interact with it. A list exposes indexing and methods such as append, while its internal storage should remain hidden behind those operations. Use del to remove a name or reference; Python reclaims objects that are no longer accessible through garbage collection.

Worked example · list abstraction

  1. Need an ordered collection: choose a list object.
  2. Read an item through L[i] and add one with L.append(x).
  3. Use the interface instead of relying on how the list is stored internally.

Compare representation and interface

Trap: An object’s visible behaviour does not reveal its internal representation.

Near miss: Directly changing assumed list storage nearly works, but can violate the list’s invariants; use its methods.

Recall · §10.1

  1. What parts form an object abstraction?
  2. Why hide representation?
Answers
  1. Data representation and an interaction interface. §10.1
  2. Users can rely on behaviour without depending on implementation details. §10.1

10.2 Classes and instances

In plain words: a class describes a kind of object; an instance is one object made from that description.

Class and instanceinstance = Class(arguments)The call creates one object of the class.

Define a class with class. A class can have data attributes and methods. For example, Coordinate is a class, while c = Coordinate(3, 4) creates an instance. The class is the shared design; each instance is a distinct object. Grouping data with its methods makes a unit easier to test and reuse. A subclass can later extend or redefine selected behaviour from a superclass; inheritance is developed in the next chapter.

Worked example · two coordinates

  1. c = Coordinate(3, 4) and origin = Coordinate(0, 0) create two instances.
  2. Both have the Coordinate type, but their coordinates differ.
  3. isinstance(c, Coordinate) checks membership in that type.

Separate class from instance

Trap: Defining a class does not itself create all its instances.

Near miss: Two variables assigned the same instance are aliases, not two separately constructed objects.

  1. What does a class define?
  2. What does isinstance check?
Answers
  1. A type’s attributes and behaviour. §10.2
  2. Whether an object is an instance of a given class or compatible subclass. §10.6

10.3 Initialisation and attributes

In plain words: initialisation gives a new instance the data it needs.

Instance assignmentself.attribute = valueStores a value on this instance.

Define __init__(self, x, y) to assign instance variables such as self.x = x. Python creates the instance and passes it as self; callers supply the other arguments. Do not pass self yourself.

Worked example · initialise a coordinate

  1. Call Coordinate(3, 4).
  2. Python makes a new Coordinate instance and calls its initialiser.
  3. The initialiser stores x and y on that instance.
  4. Read them later as c.x and c.y.

Trace instance initialisation

Trap: __init__ initialises an already-created instance; it is not called with an explicit self.

Near miss: Assigning x = x changes only a local name; self.x = x stores an instance attribute.

Recall · §10.3

  1. What does self.x = x do?
  2. Which arguments does the caller provide?
Answers
  1. Stores the supplied value on the current instance. §10.3
  2. The arguments other than self; Python supplies the instance. §10.3

10.4 Methods and self

In plain words: a method is a function defined by a class that works with an instance.

Bound method callobj.method(arg) = Class.method(obj, arg)Python supplies the instance as the first argument.

By convention, the first parameter is named self. Dot notation calls a method on an object. Python supplies that object as the first argument. Thus c.distance(origin) is equivalent to Coordinate.distance called with c and origin.

Worked example · distance between coordinates

  1. Let c = Coordinate(3, 4) and origin = Coordinate(0, 0).
  2. The method receives self = c and other = origin.
  3. It computes (3 − 0)² + (4 − 0)² = 25, then takes the square root.
  4. The distance is 5.

Trace a method call

Trap: The first argument is present even when it is omitted from the dot call.

Near miss: c.distance() lacks the required other coordinate; pass it as the second argument.

Recall · §10.4

  1. What does Python bind to self?
  2. Rewrite a dot method call using the class name.
Answers
  1. The instance before the dot. §10.4
  2. obj.method(arg) becomes Class.method(obj, arg). §10.4

10.5 String representations

In plain words: a custom string representation makes an object’s printed form informative.

String representation__str__(self) → strReturn the text for the object.

Without __str__, printing an instance usually gives a technical default representation. Define __str__ to return a string. Python calls it when print needs the object’s text. For a coordinate, it could return <3,4>.

Worked example · coordinate text

  1. For x=3 and y=4, build the text <3,4>.
  2. Return that string from __str__.
  3. print(c) displays the returned string.

Predict printed output

Trap: __str__ returns a string; printing inside it is not a substitute.

Near miss: Returning the pair (x, y) is useful data but not the required string; convert it to text.

Recall · §10.5

  1. When does Python call __str__?
  2. What type must it return?
Answers
  1. When a string form is needed, including print. §10.5
  2. str. §10.5

10.6 Types and special methods

In plain words: special methods let your class define how familiar Python operations behave.

Operator methoda + b → a.__add__(b)Implement an operation only when it has a clear meaning for the type.

type(c) reports the class of an instance; isinstance(c, Coordinate) checks its class relationship. Double-underscore methods connect syntax to behaviour: __add__ for +, __sub__ for −, __eq__ for ==, __lt__ for <, and __len__ for len. Define only operations with a sensible meaning for the type.

Worked example · addition protocol

  1. Suppose a + b is meaningful for a class.
  2. Python looks for the class’s addition behaviour, commonly a.__add__(b).
  3. That method should return the defined result, not merely print it.

Match operators to methods

Trap: A special method should preserve the expected meaning of its operator.

Near miss: Defining __add__ to concatenate unrelated objects may run, but gives the operator a confusing contract; choose an operation that fits the type.

Recall · §10.6

  1. Which method supports ==?
  2. What is checked by isinstance?
Answers
  1. __eq__. §10.6
  2. Whether the object belongs to the requested class relationship. §10.6

10.7 Fraction objects

In plain words: a fraction object stores a numerator and denominator, then offers meaningful fraction operations.

Fraction representationvalue = numerator / denominatorThe denominator must be non-zero.

The lecture uses fractions as a design exercise: decide the internal representation, then define an interface such as addition, subtraction, inversion, float conversion and printing. The representation should preserve the denominator rule; arithmetic should return a fraction object or another clearly specified type.

Worked example · add two fractions

  1. Represent 1⁄2 as numerator 1 and denominator 2, and 1⁄3 as 1 and 3.
  2. Use the common denominator: 1·3 + 1·2 over 2·3.
  3. The result is 56, represented by numerator 5 and denominator 6.
  4. Check: 56 is between 12 and 1, as expected.

For a robust class, also decide how to reject a zero denominator and whether to reduce fractions. Those are design choices to state explicitly; the lecture’s slides do not specify them.

Design a fraction interface

Trap: A class is not complete merely because it stores two numbers; its operations need defined behaviour.

Near miss: Inverting a fraction with zero numerator would put zero in the denominator; reject that operation or define a clear exception.

Recall · §10.7

  1. Name two data attributes for a fraction.
  2. Name two operations its interface can offer.
Answers
  1. Numerator and denominator. §10.7
  2. For example, addition and inversion, or float conversion and printing. §10.7
