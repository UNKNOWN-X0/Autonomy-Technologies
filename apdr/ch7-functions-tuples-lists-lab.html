Functions, Tuples, and Lists Lab

Algorithms, Programming, and Data Representation · Module 92313 · Chapter 7

Predict what a short program prints, then step through it the way Python runs it: the running line, a frame of names for every call, the lists and tuples those names point at, and the output.

How the lab works

  1. Predict. Commit to an answer before the program runs.
  2. Rate your confidence. A sure but wrong answer marks an idea to revisit first.
  3. Reveal. Watch the program run line by line. Each name is drawn in its frame; an arrow means it points at a list or tuple on the right, and two arrows to one box mean one object with two names. Functions made with def are left out of the main program’s frame to save room.
  4. Explore. Press Explore freely at any time, or finish the four challenges, to run your own values or your own short program.

7.9 Aliasing and cloning: one list or two?

A name points at a list; it does not hold a copy. Two arrows to one box are aliases, and a change through either shows through both. A clone is a second box.
