Statements and connectives

A statement is a sentence that is either true (T) or false (F), never both. “The formula is beautiful” is not one.

T TFTTTT
T FFFTFF
F TTFTTF

The notes write 1 for T and 0 for F. ∨ is inclusive (both may be true). A ⇒ B is false only in the row T ⇒ F, so a false premise makes it true. Tautology: T in every row; contradiction: F in every row. n letters give 2n rows.
Equivalences to know
  • ¬¬A ⇔ A
  • A ⇒ B ⇔ ¬A ∨ B ⇔ ¬B ⇒ ¬A (contrapositive)
  • ¬(A ⇒ B) ⇔ A ∧ ¬B
  • A ⇔ B ⇔ (A ⇒ B) ∧ (B ⇒ A)
  • De Morgan: ¬(A ∧ B) ⇔ ¬A ∨ ¬B; ¬(A ∨ B) ⇔ ¬A ∧ ¬B
  • A ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C); swap ∧, ∨ for the twin
  • ∧ and ∨ are commutative and associative: order and brackets are free
  • Majority vote of 3 sensors: (A ∧ B) ∨ (A ∧ C) ∨ (B ∧ C); (A ∧ B) ∨ (A ∧ ¬B) ⇔ A
The converse B ⇒ A is not equivalent to A ⇒ B. Prove an equivalence: equal truth columns in every row. Show “not a tautology”: one row giving F.

Quantifiers
  • ∀x ∈ M: P(x) — for all x
  • ∃x ∈ M: P(x) — for at least one x
  • ∃!x — exactly one
¬∀x P(x) ⇔ ∃x ¬P(x)¬∃x P(x) ⇔ ∀x ¬P(x)Negate: swap every ∀ ↔ ∃ and negate the end: ¬(∀x ∃y: x < y) ⇔ ∃x ∀y: x ≥ y. Order matters: ∀y ∃x: x < y is true in ℤ, ∃x ∀y: x < y is false everywhere (take y = x). One counterexample kills a ∀; one example proves an ∃.
Proof patterns
  • Direct: assume A, derive B.
  • Contrapositive: assume ¬B, derive ¬A.
  • Contradiction: assume the claim is false, reach something false.
  • A ⇔ B: prove both directions.
  • Set equality: two inclusions, or a chain of ⇔ on “x ∈ …”.
Sets: notation
  • a ∈ A: a is an element of A; ∅: the empty set; |A|: number of elements
  • A ⊂ B: every element of A lies in B (∅ ⊂ A and A ⊂ A always)
  • A = B ⇔ A ⊂ B and B ⊂ A
  • [a, b] closed (ends in), (a, b) open (ends out), [a, b) half-open
  • ℕ = {1, 2, 3, …}, ℕ0 = ℕ ∪ {0}; ℕ ⊊ ℤ ⊊ ℚ ⊊ ℝ
  • A ⊊ B: A ⊂ B and A ≠ B (proper subset)
Set operations
  • A ∪ B: in A or B; A ∩ B: in both
  • A \ B: in A and not in B (= A ∩ Bc)
  • Ac = X \ A: always say what X is
  • A × B = {(a, b) : a ∈ A, b ∈ B}: ordered pairs; |A × B| = |A| · |B|; A × ∅ = ∅
  • 𝒫(A): all subsets, ∅ and A included; |𝒫(A)| = 2|A|; X ∈ 𝒫(A) ⇔ X ⊂ A
{1, 2} ∉ 𝒫({1, 2} × {1}): the elements of that product are pairs, not numbers.
Many sets
  • ⋃ Ak (k = 1, …, n): x lies in at least one Ak
  • ⋂ Ak: x lies in every Ak
  • A1 × … × An: ordered n-tuples (x1, …, xn), xk ∈ Ak
  • ℝ2 = ℝ × ℝ: the plane; [1, 3] × [1, 2]: a rectangle; {0, 1}3: the 8 corners of the unit cube
Set laws
  • (A ∪ B)c = Ac ∩ Bc; (A ∩ B)c = Ac ∪ Bc
  • A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C), and with ∩, ∪ swapped
  • A \ (B ∪ C) = (A \ B) ∩ (A \ C); A \ (B ∩ C) = (A \ B) ∪ (A \ C)
  • A \ (B \ C) = (A \ B) ∪ (A ∩ C)
  • (Ac)c = A; ∩ and ∪ are commutative and associative
Logic ↔ sets: ∧ ↔ ∩, ∨ ↔ ∪, ¬ ↔ complement, ⇒ ↔ ⊂, ⇔ ↔ =. Intervals: check each endpoint; (1, 3)c in ℝ is (−∞, 1] ∪ [3, ∞).
Number systems
  • ℕ ⊊ ℤ ⊊ ℚ ⊊ ℝ; ℚ = {pq : p ∈ ℤ, q ∈ ℕ, no common factor}; irrational: ℝ \ ℚ (√2, π, e)
  • ℝ is a complete ordered field: 9 field axioms (+ and · with 0, 1 and inverses), 4 order axioms, 1 completeness axiom
  • x1/n for x ≥ 0 is sup{r ∈ ℚ : r ≥ 0, rn ≤ x}: the one w ≥ 0 with wn = x
Order axioms: consequences
  • a · 0 = 0 (from a · 0 = a(0 + 0) = a · 0 + a · 0)
  • −a = (−1) · a; (−a)(−b) = ab
  • ab = 0 ⇒ a = 0 or b = 0
  • a ≠ 0 ⇒ a2 > 0; hence 1 = 12 > 0
  • a < b ⇒ a + c < b + c
  • a < b and c > 0 ⇒ ac < bc; c < 0 ⇒ ac > bc (flip!)
  • 0 < a < b ⇒ 1a > 1b
In an axiom proof cite one axiom per step: commutative, associative, distributive, 0 and 1, inverses, trichotomy, transitivity, + and positive · keep order.
Bounds, supremum, infimum
  • Upper bound s: x ≤ s for every x ∈ M
  • sup M = S: x ≤ S for all x ∈ M, and S ≤ T for every upper bound T (the least one); inf: the greatest lower bound
  • max M: a sup that lies in M (same for min, inf)
  • Completeness: every non-empty M ⊂ ℝ bounded above has a sup in ℝ
Show s = sup M: (1) x ≤ s for all x ∈ M; (2) for every ε > 0 some x ∈ M has x > s − ε.

Solving with | | and roots
  1. Find where each |…| is zero; these points cut ℝ into pieces.
  2. On each piece drop the bars with the right sign (|x − 3| = 3 − x for x < 3).

Induction
  1. Base: check A(n0) for the first n.
  2. Step: assume A(n) (hypothesis), prove A(n + 1).
  3. Conclude A(n) for all n ≥ n0.
Sums: Sn+1 = Sn + (new term), insert the hypothesis, factor. Divisibility: 5n+1 − 1 = 5(5n − 1) + 4. Inequality: Bernoulli (1 + x)n ≥ 1 + nx for x ≥ −1; it even holds for x ≥ −2 (two-step induction: bases 1 and 2, step n → n + 2). Two-step recurrences need two base cases.
Maps
  • f: X → Y, x ↦ f(x): domain X, codomain Y, one output per input
  • Image f(A) = {f(x) : x ∈ A}; Im f = f(X)
  • Preimage f−1(B) = {x ∈ X : f(x) ∈ B}: exists for every f
  • Equal maps: same domain, codomain and rule
  • Injective f has f−1: Im f → X. Injectivity ignores the codomain; surjectivity depends on it
Injective, surjective, bijective
  • Injective: f(x1) = f(x2) ⇒ x1 = x2 (each horizontal line hits at most once)
  • Surjective (onto): every y ∈ Y has x with f(x) = y, i.e. Im f = Y
  • Bijective: both (exactly one x for each y)
Prove injective: assume f(x1) = f(x2), deduce x1 = x2. Disprove: two inputs, same output, e.g. (x − 2)2 at 1 and 3. Prove onto: solve y = f(x), check x ∈ X. Strictly monotone ⇒ injective (not conversely). Repair: restrict the domain to one side of a vertex, shrink the codomain to Im f.
Inverse and composition
  • Bijective f has f−1: Y → X, f−1(y) = x ⇔ f(x) = y; find it by solving y = f(x) for x
  • f−1 ∘ f = idX, f ∘ f−1 = idY; graph mirrored in y = x
  • (g ∘ f)(x) = g(f(x)): f first; domain {x : f(x) ∈ D(g)}
  • Associative, not commutative; (g ∘ f)−1 = f−1 ∘ g−1
f, g injective ⇒ g ∘ f injective; both onto ⇒ g ∘ f onto; g ∘ f injective ⇒ f injective; g ∘ f onto ⇒ g onto. Range of g ∘ f: find the range of f, then apply g to it.

Exam Sheet I · Side 2 · Question types and methods

Personal exam sheet based on the MEI lecture notes, Chapters 1–3, and Exercise Sheets 1–4, in my own words; check what your exam allows before you take it in. Not an official FAU publication. Made by Thanate Amornjiraporn (Focus).

Logic · translate a sentence

SS 1.4e: Translate: “The mirror breaks only if it is made of glass.”

SS 1.4a: Is “The formula is beautiful” a logical statement?

Method: A statement must assert something with a definite truth value. Name each simple statement. Translate “A if B” as B ⇒ A, “A only if B” as A ⇒ B, “unless B, A” as ¬B ⇒ A. Bracket each clause before joining clauses.

Check: “But” means ∧; “or” is inclusive unless stated otherwise.

Logic · truth tables and equivalence

SS 1.4d: Disprove that (A ⇒ B) ⇒ (B ⇒ A) is a tautology.

SS 1.4b: Verify ¬(A ∧ B) ⇔ ¬A ∨ ¬B and A ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C) by truth tables.

Method: For n letters, list all 2n truth assignments. Compute inner brackets first, then connectives, then the final column. Compare final columns row by row.

Check: A tautology needs every row true. One false row disproves it; one differing row disproves equivalence. A ⇒ B is false only for T ⇒ F.

Logic · quantified claims

SS 1.6a: In each of ℕ, ℤ and ℝ+, test and negate ∃x ∀y: x < y and ∀y ∃x: x < y. Repeat with x + y = 1.

Method: Read quantifiers from left to right. For ∀x ∃y, take an arbitrary x and construct y in the stated set. For ∃y ∀x, choose one fixed y that works for every x. Negate by swapping every ∀ and ∃, then negating the final relation.

Check: A witness must belong to the domain. To disprove ∀, give one counterexample; to disprove ∃, show every candidate fails.

Sets · intervals and finite sets

SS 1.5a: Let A = (−2,1], B = (−1,1), C = {−2,0,1}. Find A ∩ B ∩ C, A ∩ (B ∪ C), (A ∪ B)c and (A ∖ B) ∖ C in ℝ.

SS 2.6c: For A = [1,3), B = (2,5] in ℝ, find Ac, Bc, (A ∪ B)c, (A ∩ B)c and A ∖ B.

Method: Mark all endpoints and isolated points on a number line. Test membership on each intervening interval and at each endpoint. Keep regions satisfying “or”, “and”, or “in A but not B”; write their union.

Check: Complement depends on the universal set. Strict inequalities exclude endpoints; check isolated roots separately.

Sets · power sets and products

SS 1.5b: List 𝒫({a, b, c}).

SS 1.5b: List 𝒫({1,2} × {1}) and test membership of {1,2}.

Method: For a power set, list subsets by size, from ∅ to A; check the count 2|A|. For a product, list ordered pairs with first entry in A and second in B; check |A|·|B|.

Check: An element of 𝒫(A) is a subset of A. An element of A × B is a pair. Empty factors give an empty product.

Sets · prove an identity or inclusion

SS 1.5c: Prove A ∖ (B ∖ C) = (A ∖ B) ∪ (A ∩ C).

SS 2.6a–b: Prove A ⊂ C and B ⊂ D imply A × B ⊂ C × D. Is the converse always true?

Method: Take an arbitrary element. Translate membership into ∧, ∨ and ¬; apply logical laws; translate back. Use ⇔ throughout for equality, or prove both inclusions. For products, take a pair and handle each coordinate.

Check: To disprove a claim, give explicit sets and an element where membership differs. Check empty sets before claiming a converse.

Real numbers · bounds and extrema

Question: “Find sup, inf, max and min.”

Method: Identify a candidate upper bound S and prove every element ≤ S. Then show that for every ε > 0 an element exceeds S − ε. Reverse inequalities for the infimum.

Check: A supremum is a maximum only if it belongs to the set. For alternating sequences, examine even and odd terms separately.

Real numbers · absolute-value inequalities

SS 2.5b(i): Solve |x + 3| + |x − 3| > 8.

Method: Find the zeros of every expression inside bars. Split the line there. In each region replace each absolute value by the expression or its negative, solve, and intersect with that region. Unite the surviving pieces.

Check: Check every boundary in the original inequality. Multiplication by a negative quantity reverses the inequality.

Real numbers · square-root inequalities

SS 2.5b(ii): Solve √(x − 4)(x − 1) ≤ 2 − x.

Method: Require A(x) ≥ 0 and B(x) ≥ 0. On that domain, square to obtain A(x) ≤ B(x)2. Solve and intersect with both initial restrictions.

Check: For √A(x) ≥ B(x), B(x) ≤ 0 is already true wherever the root exists; square only the B(x) > 0 branch.

Real numbers · sketch a region

SS 2.5a: Sketch |x| + |y − 2| < 5.

SS 2.6d: In ℝ2, find the complement of [1,3] × [1,2].

Method: For r > 0, mark the centre (a,b) and the four vertices (a ± r,b), (a,b ± r). Join adjacent vertices. Test the centre to choose the inside or outside. For a rectangle’s complement, negate “x in its interval AND y in its interval”: either coordinate outside is enough.

Check: Use a solid boundary for ≤ or ≥ and a dashed one for < or >. For r = 0 or r < 0, inspect the inequality directly.

Real numbers · closure and decimal error

SS 3.8a–c: For D = {m10n: m ∈ ℤ, n ∈ ℕ0}, prove closure under + and ·, prove 13 ∉ D, and prove 0 ≤ x − xn < 10−n for xn = ⌊10nx⌋10n.

SS 3.8d: Compare (a + b) + c and a + (b + c) in double precision for a = 1016, b = −1016, c = 1.

Method: Write arbitrary members in the defining form. For finite decimals, use a common power-of-ten denominator for addition and multiply numerators and denominators for products. For truncation use m ≤ 10nx < m + 1, then divide by 10n.

Check: To show a rational is not a finite decimal, assume a power-of-ten denominator and derive a divisibility contradiction. A single result outside the set disproves closure. Distinguish exact arithmetic from floating-point rounding and sensitivity to operation order.

Sums · find the general term

SS 2.7a: Write using ∑: 102 − 192 + 82 − 172 + ⋯ + 22 − 112.

Method: Choose the first index, express each term using it, and solve for the last index. Substitute the first, second and last indices to check the formula. For a shift j = k + c, change both limits and every occurrence of k.

Check: Check the number of terms: upper limit − lower limit + 1. Alternating signs and paired terms must follow the same pattern.

Sums · cancellation and telescoping

SS 2.7b(i): For q ≠ 0, simplify: ∑k=0n qk − ∑k=0n+1 qk−1.

SS 2.7b(ii): Simplify ∏j=2n(1 − 2j(j + 1)), n ≥ 2.

Method: Align index ranges and write the first and last few terms. Separate unmatched endpoints. For products, factor each numerator and denominator, split into simpler products, and cancel matching factors.

Check: Keep the factors or terms left at both ends. Check denominators and the smallest allowed index before cancelling.

Binomials · recognize a theorem

SS 2.7b(iii): Evaluate ∑k=0n(−1)kC(n,k), n ≥ 1.

SS 3.9b–c: Compute D0, …, D7 and prove Dn = Fn+1, where Dn = ∑k=0nC(n − k,k); use C(r,k) = 0 for k > r and F1 = F2 = 1, Fn+2 = Fn+1 + Fn.

Method: Match the terms to C(n,k)an−kbk. Choose a and b to reproduce signs and powers, then use (a + b)n. For Pascal diagonal sums, apply Pascal’s identity inside the sum and shift indices to obtain a recurrence.

Check: Record summation limits and boundary terms. A recurrence of order two needs two initial values.

Counting · select the model

SS 2.7c: A box has 12 striped and 4 white marbles. How many six-marble selections contain at most two striped marbles?

Method: Decide whether order matters and repetition is allowed. Use C(n,k) for unordered selections, n! divided by (n − k)! for ordered selections without repeats, and nk with repeats. Multiply successive choices; add disjoint cases.

Check: Unordered pairs use C(n,2); directed pairs use n(n − 1). With category limits, sum over every feasible category count.

Counting · restrictions and complements

SS 2.7d: Each member tells every other member one riddle. There are 272 tellings. How many members?

Method: Use total minus none for “at least one”. For “at most k”, enumerate feasible counts and add their selection products. For an unknown group size, form the counting equation, solve it, then keep admissible integers.

Check: Probability needs equally likely outcomes for favourable divided by total. Check capacity limits, nonnegative counts and duplicate counting.

Induction · sums and products

SS 3.6a: Prove 1 + 2 + ⋯ + n = n(n + 1)2 for n ∈ ℕ.

SS 3.5: Prove ∑k=0n xk = 1 − xn+11 − x, x ≠ 1, n ∈ ℕ.

SS 3.6b–c: Prove the square-sum and cube-sum formulas listed on Side 1 by induction.

Method: Write and verify the first allowed n. Assume the exact formula for n. Express the n + 1 case as the old sum plus its next term, or old product times its next factor. Substitute the hypothesis and simplify to the target for n + 1.

Check: Write the target before simplifying. Do not assume the n + 1 claim. End by stating the full range of n.

Induction · inequalities and divisibility

Question: “Prove an inequality or that d divides an expression.”

Method: For inequalities, expose the n-case and use the hypothesis only after checking the sign of every multiplier. For divisibility, rewrite the next expression as a multiple of the old expression plus an explicit multiple of d.

Check: If the step advances by two, prove both starting cases. Parameter restrictions must hold at every multiplication.

Maps · domain and range

SS 3.7a: Find the images of f(x) = x2 − 4x + 3 on ℝ and g(x) = √1 − x on (−∞,1].

Method: Require nonzero denominators, nonnegative radicands and positive log arguments. Intersect these with the given domain. For the range, use a vertex, monotonicity, or solve y = f(x) and determine which y admit an allowed x.

Check: A limiting value is not automatically attained. Check open endpoints and distinguish image from the stated codomain.

Maps · injective, onto, bijective

SS 3.7a: Classify h: ℝ3 → ℝ2, h(x,y,z) = (x + y,y + z).

SS 4.7a–c: Prove strict increase or decrease implies injectivity. Must an injective function be strictly monotone?

Method: Injective: assume f(u) = f(v) and try to prove u = v; otherwise exhibit distinct inputs with equal outputs. Onto: take arbitrary y in the codomain and solve f(x) = y with x in the domain. Both properties give bijectivity.

Check: Strict monotonicity: order two distinct inputs and show their outputs differ. A counterexample to the converse must violate both strict increase and strict decrease. For vector maps, solve the coordinate equations. A free input parameter can reveal non-injectivity; a constraint on outputs can disprove surjectivity.

Maps · restrict and invert

SS 4.4a: Make f(x) = −x2 + 6x − 5 on ℝ and g(x) = 11 + x on [0,∞), both with codomain ℝ, bijective by restriction; find their inverses.

Method: Restrict a non-injective curve to a branch where it is injective. Set the codomain equal to that branch’s image. Solve y = f(x) for x, choosing the root sign fixed by the branch. State inverse domain and range.

Check: For a quadratic, complete the square first. Check both compositions give the identity on their respective domains.

Maps · compose and determine its range

SS 3.7b(ii): For f(x) = x2 − 4x + 3 and g(x) = √1 − x (x ≤ 1), find g ∘ f, its domain and image.

SS 4.4b(iv): For g(x) = 11 + x, x ≥ 0, find g ∘ g, its domain and image.

Method: Substitute f(x) into g. Require x in the domain of f and f(x) in the domain of g. Determine the image of f on this restricted domain, then apply g to that image.

Check: Simplifying a formula does not restore excluded inputs. Composition order matters; keep restrictions before cancelling.

Maps · prove composition properties

SS 4.5i: Prove: injective g ∘ f implies injective f.

SS 4.5ii–iv: Prove g ∘ f onto ⇒ g onto, and f,g onto ⇒ g ∘ f onto. Construct injective g ∘ f with non-injective g.

Method: For injectivity, start with f(u) = f(v), apply g and use the assumed injectivity. For surjectivity, take arbitrary output z and use z = g(f(x)); f(x) supplies the intermediate preimage. To prove both onto imply the composition onto, choose preimages twice.

Check: To disprove a converse, build a small finite mapping and check every input and output. Strict monotonicity implies injectivity, but the converse can fail.

Polynomials · roots with a parameter

SS 4.6a: Find and factor the roots of 5x4 + 20x2 − 25. Classify the real roots of ax2 + 2x + 1 for every real a.

Method: First separate parameters that make the leading coefficient zero. For a genuine quadratic, inspect Δ = b2 − 4ac. For even powers, substitute u = x2, solve in u, retain u ≥ 0 for real x, then take both signs.

Check: A double root counts once as a distinct root. A known root x0 gives the factor x − x0; check the remaining factor.

Trigonometry · prove or derive an identity

SS 4.8b: Derive tan 2x = 2 tan x1 − tan2x where defined.

SS 4.6b: Disprove cos(3x) = 3cos x and derive the correct triple-angle formula.

SS 4.8a: Derive the tangent addition and subtraction formulas from sine and cosine.

Method: Expand a sum angle, such as 3x = 2x + x. Insert double-angle identities and use sin2x + cos2x = 1 to collect powers. For tangent, divide sine’s addition formula by cosine’s and simplify the quotient.

Check: Keep all nonzero-denominator conditions. One numerical counterexample disproves an identity; examples alone never prove it.

Trigonometry · exact angles and polar form

SS 4.8c: Find tan(π12) exactly.

Method: Express the angle as a sum or difference of standard angles, substitute exact values and simplify. For polar form, find r from x² + y², choose the angle using both coordinate signs, and check x = r cos φ and y = r sin φ.

Check: The arctangent ratio alone loses the quadrant. Handle x = 0 separately; the origin has no unique angle.
