Side 1 · Rules from Exercises 1–4

Statements and connectives

A statement is a sentence that is either true (T) or false (F), never both. “The formula is beautiful” is not one.

A B¬AA∧BA∨BA⇒BA⇔B
T TFTTTT
T FFFTFF
F TTFTTF
F FTFFTT
∨ is inclusive (both may be true). A ⇒ B is false only in the row T ⇒ F, so a false premise makes it true. Tautology: T in every row; contradiction: F in every row. n letters give 2n rows.
Equivalences to know
  • ¬¬A ⇔ A
  • A ⇒ B ⇔ ¬A ∨ B ⇔ ¬B ⇒ ¬A (contrapositive)
  • ¬(A ⇒ B) ⇔ A ∧ ¬B
  • A ⇔ B ⇔ (A ⇒ B) ∧ (B ⇒ A)
  • De Morgan: ¬(A ∧ B) ⇔ ¬A ∨ ¬B; ¬(A ∨ B) ⇔ ¬A ∧ ¬B
  • A ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C); swap ∧, ∨ for the twin
The converse B ⇒ A is not equivalent to A ⇒ B. Prove an equivalence: equal truth columns in every row. Show “not a tautology”: one row giving F.

Quantifiers
  • ∀x ∈ M: P(x) — for all x
  • ∃x ∈ M: P(x) — for at least one x
  • ∃!x — exactly one
¬∀x P(x) ⇔ ∃x ¬P(x)¬∃x P(x) ⇔ ∀x ¬P(x)Negate: swap every ∀ ↔ ∃ and negate the end: ¬(∀x ∃y: x < y) ⇔ ∃x ∀y: x ≥ y. Order matters: ∀y ∃x: x < y is true in ℤ, ∃x ∀y: x < y is false everywhere (take y = x). One counterexample kills a ∀; one example proves an ∃.
Proof patterns
  • Direct: assume A, derive B.
  • Contrapositive: assume ¬B, derive ¬A.
  • Contradiction: assume the claim is false, reach something false.
  • A ⇔ B: prove both directions.
  • Set equality: two inclusions, or a chain of ⇔ on “x ∈ …”.
Sets: notation
  • a ∈ A: a is an element of A; ∅: the empty set; |A|: number of elements
  • A ⊂ B: every element of A lies in B (∅ ⊂ A and A ⊂ A always)
  • A = B ⇔ A ⊂ B and B ⊂ A
  • [a, b] closed (ends in), (a, b) open (ends out), [a, b) half-open
  • ℕ = {1, 2, 3, …}, ℕ0 = ℕ ∪ {0}; ℕ ⊊ ℤ ⊊ ℚ ⊊ ℝ
Set operations
  • A ∪ B: in A or B; A ∩ B: in both
  • A \ B: in A and not in B (= A ∩ Bc)
  • Ac = X \ A: always say what X is
  • A × B = {(a, b) : a ∈ A, b ∈ B}: ordered pairs; |A × B| = |A| · |B|; A × ∅ = ∅
  • 𝒫(A): all subsets, ∅ and A included; |𝒫(A)| = 2|A|; X ∈ 𝒫(A) ⇔ X ⊂ A
{1, 2} ∉ 𝒫({1, 2} × {1}): the elements of that product are pairs, not numbers.
Set laws
  • (A ∪ B)c = Ac ∩ Bc; (A ∩ B)c = Ac ∪ Bc
  • A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C), and with ∩, ∪ swapped
  • A \ (B ∪ C) = (A \ B) ∩ (A \ C); A \ (B ∩ C) = (A \ B) ∪ (A \ C)
  • A \ (B \ C) = (A \ B) ∪ (A ∩ C)
Logic ↔ sets: ∧ ↔ ∩, ∨ ↔ ∪, ¬ ↔ complement, ⇒ ↔ ⊂. Intervals: check each endpoint; (1, 3)c in ℝ is (−∞, 1] ∪ [3, ∞).
Order axioms: consequences
  • a · 0 = 0 (from a · 0 = a(0 + 0) = a · 0 + a · 0)
  • −a = (−1) · a; (−a)(−b) = ab
  • ab = 0 ⇒ a = 0 or b = 0
  • a ≠ 0 ⇒ a2 > 0; hence 1 = 12 > 0
  • a < b ⇒ a + c < b + c
  • a < b and c > 0 ⇒ ac < bc; c < 0 ⇒ ac > bc (flip!)
  • 0 < a < b ⇒ 1a > 1b
In an axiom proof cite one axiom per step: commutative, associative, distributive, 0 and 1, inverses, trichotomy, transitivity, + and positive · keep order.
Bounds, supremum, infimum
  • Upper bound s: x ≤ s for every x ∈ M
  • sup M: the least upper bound; inf M: the greatest lower bound
  • max M: a sup that lies in M (same for min, inf)
  • Completeness: every non-empty M ⊂ ℝ bounded above has a sup in ℝ
Show s = sup M: (1) x ≤ s for all x ∈ M; (2) for every ε > 0 some x ∈ M has x > s − ε.

Solving with | | and roots
  1. Find where each |…| is zero; these points cut ℝ into pieces.
  2. On each piece drop the bars with the right sign (|x − 3| = 3 − x for x < 3).
  3. Solve, keep only solutions inside that piece, unite the pieces.
Roots: radicand ≥ 0 first. For a root ≤ R also need R ≥ 0. Square only when both sides are ≥ 0, then check the ends. Regions: |x| + |y| = r is a diamond with corners (±r, 0), (0, ±r); |x − a| + |y − b| moves its centre to (a, b); < inside, ≤ with the edge.

Induction
  1. Base: check A(n0) for the first n.
  2. Step: assume A(n) (hypothesis), prove A(n + 1).
  3. Conclude A(n) for all n ≥ n0.
Sums: Sn+1 = Sn + (new term), insert the hypothesis, factor. Divisibility: 5n+1 − 1 = 5(5n − 1) + 4. Inequality: Bernoulli (1 + x)n ≥ 1 + nx for x ≥ −1. Two-step recurrences need two base cases.
Maps
  • f: X → Y, x ↦ f(x): domain X, codomain Y, one output per input
  • Image f(A) = {f(x) : x ∈ A}; Im f = f(X)
  • Preimage f−1(B) = {x ∈ X : f(x) ∈ B}: exists for every f
  • Equal maps: same domain, codomain and rule
Injective, surjective, bijective
  • Injective: f(x1) = f(x2) ⇒ x1 = x2 (each horizontal line hits at most once)
  • Surjective (onto): every y ∈ Y has x with f(x) = y, i.e. Im f = Y
  • Bijective: both (exactly one x for each y)
Prove injective: assume f(x1) = f(x2), deduce x1 = x2. Disprove: two inputs, same output, e.g. (x − 2)2 at 1 and 3. Prove onto: solve y = f(x), check x ∈ X. Strictly monotone ⇒ injective (not conversely). Repair: restrict the domain to one side of a vertex, shrink the codomain to Im f.
Inverse and composition
  • Bijective f has f−1: Y → X, f−1(y) = x ⇔ f(x) = y; find it by solving y = f(x) for x
  • f−1 ∘ f = idX, f ∘ f−1 = idY; graph mirrored in y = x
  • (g ∘ f)(x) = g(f(x)): f first; domain {x : f(x) ∈ D(g)}
  • Associative, not commutative; (g ∘ f)−1 = f−1 ∘ g−1
f, g injective ⇒ g ∘ f injective; both onto ⇒ g ∘ f onto; g ∘ f injective ⇒ f injective; g ∘ f onto ⇒ g onto. Range of g ∘ f: find the range of f, then apply g to it.

  • Biquadratic: u = x2 (or x4) turns it into a quadratic
Parameter in front of x2: treat a = 0 (a line) separately.
exp, ln, powers

  • ax = ex ln a; loga x = ln xln a (a > 0, a ≠ 1)

Side 2 · Self-Study tasks, worked

SS 1.4a · statement or not?
  • “If my father has a sister, …”: a statement (true or false, even if you do not know which)
  • “The formula is beautiful”: no definite truth value, so not a statement
SS 1.4c · conditionals with false parts

C, D, P: cats, dogs, parrots have wings (all F).

  • cats only if dogs: C ⇒ D
  • parrots only if dogs: P ⇒ D
  • parrots if dogs: D ⇒ P
  • (C ∨ D) ⇒ (C ∧ D)
All four are true: each premise is false, and F ⇒ anything is T.
SS 1.4e · if, only if, unless

B: mirror breaks, G: glass, W: high on the wall.

  • breaks if glass: G ⇒ B
  • breaks only if glass: B ⇒ G
  • unless glass, not break: ¬G ⇒ ¬B ⇔ B ⇒ G (same as the last)
  • high, but not break unless glass: W ∧ (B ⇒ G)
SS 1.4d · not a tautology

(A ⇒ B) ⇒ (B ⇒ A) with A = F, B = T: T ⇒ F = F. One false row is enough.

SS 1.5a · intervals and points

A = (−2, 1], B = (−1, 1), C = {−2, 0, 1} (roots of x(x + 2)(x − 1)).

  • A ∩ B = (−1, 1); A ∩ B ∩ C = {0}
  • A ∩ (B ∪ C) = (−1, 1]
  • (A ∪ B)c = (−∞, −2] ∪ (1, ∞)
  • (A \ B) \ C = (−2, −1]
SS 1.5b · power sets

𝒫({a, b, c}) = {∅, {a}, {b}, {c}, {a, b}, {a, c}, {b, c}, {a, b, c}}: 23 = 8. {1, 2} × {1} = {(1, 1), (2, 1)}, so 𝒫 has 4 members and {1, 2} ∉ 𝒫.

SS 2.5 · regions and inequalities
  • |x| + |y − 2| < 5: inside of the diamond with corners (±5, 2), (0, 7), (0, −3); edge excluded
  • |x + 3| + |x − 3| > 8: on [−3, 3] the sum is 6 (no); x > 3: 2x > 8 ⇒ x > 4; x < −3: −2x > 8 ⇒ x < −4. Answer (−∞, −4) ∪ (4, ∞)
  • √(x − 4)(x − 1) ≤ 2 − x: radicand ≥ 0 ⇔ x ≤ 1 or x ≥ 4; right side ≥ 0 ⇔ x ≤ 2; so x ≤ 1. Square: x2 − 5x + 4 ≤ x2 − 4x + 4 ⇔ x ≥ 0. Answer [0, 1]
SS 2.6 · products and complements
  • A ⊂ C, B ⊂ D ⇒ A × B ⊂ C × D: take (a, b), then a ∈ C, b ∈ D
  • Converse false: A = {1}, B = ∅ gives ∅ ⊂ anything; true if A, B ≠ ∅
  • A = [1, 3), B = (2, 5]: Ac = (−∞, 1) ∪ [3, ∞); A ∩ B = (2, 3); A \ B = [1, 2]
  • ([1, 3] × [1, 2])c: x < 1 or x > 3 or y < 1 or y > 2, i.e. ((−∞, 1) ∪ (3, ∞)) × ℝ ∪ ℝ × ((−∞, 1) ∪ (2, ∞))
  • Complements: (A ∪ B)c = (−∞, 1) ∪ (5, ∞); (A ∩ B)c = (−∞, 2] ∪ [3, ∞)

SS 3.7 · classify and compose
  • f(x) = (x − 2)2 − 1: range [−1, ∞); not injective (f(1) = f(3) = 0), not onto ℝ. On [2, ∞) → [−1, ∞): f−1(y) = 2 + √y + 1

  • h(x, y, z) = (x + y, y + z): onto (use (u, 0, v)), not injective (add (−t, t, −t))

SS 3.9 · Fibonacci in Pascal

Dn = ∑ C(n − k, k): 1, 1, 2, 3, 5, 8, 13, 21 = Fn+1. Pascal inside the sum splits Dn+2 into Dn+1 + Dn; two base cases D0 = D1 = 1.

SS 4.4 · classify and compose
  • f(x) = −x2 + 6x − 5 = 4 − (x − 3)2: range (−∞, 4]; on [3, ∞): f−1(y) = 3 + √4 − y
  • g(x) = 11 + x, x ≥ 0: values (0, 1], decreasing; g−1(y) = 1y − 1
  • h(x, y) = (x, x + y, y): injective, image the plane b = a + c, not onto ℝ3
  • f ∘ exp: range (−∞, 4]; g ∘ f = 15 − (x − 3)2 on [1, 5], range [15, 1]
  • g ∘ exp = 11 + ex, range (0, 1); g ∘ g = 1 + x2 + x, range [12, 1)
SS 4.5 · composition facts
  • g ∘ f injective: f(x1) = f(x2) ⇒ g(f(x1)) = g(f(x2)) ⇒ x1 = x2, so f injective
  • g ∘ f onto: z = g(f(x)) gives y = f(x) with g(y) = z, so g onto
  • f, g onto ⇒ g ∘ f onto: for z pick y with g(y) = z, then x with f(x) = y
  • g ∘ f injective while g is not: X = {a}, f(a) = 0, g(0) = g(1)
SS 4.6 · roots; cos 3x
  • 5x4 + 20x2 − 25: u = x2, u2 + 4u − 5 = (u − 1)(u + 5) ⇒ 5(x − 1)(x + 1)(x2 + 5); real roots ±1, complex ±i√5
  • ax2 + 2x + 1: a = 0 one root −12; Δ = 4(1 − a): two for a < 1 (a ≠ 0), double root −1 at a = 1, none for a > 1
  • cos 3x = cos 2x cos x − sin 2x sin x = 4cos3 x − 3 cos x ≠ 3 cos x (try x = 0)
SS 4.7 · monotone and injective
  • Strictly increasing or decreasing ⇒ injective: x ≠ y gives f(x) < f(y) or >
  • Converse false: swap 0 and 1, fix the rest: bijective, not monotone
  • exp strictly increasing and onto (0, ∞) ⇒ bijective, inverse ln
SS 4.8 · tangent formulas
  • Divide the sin and cos addition formulas by cos x cos y: tan(x ± y) = tan x ± tan y1 ∓ tan x tan y
  • tan 2x = 2 tan x1 − tan2 x
  • tan π12 = tan(π3 − π4) = √3 − 11 + √3 = 2 − √3
Before you hand in
  • Endpoints: open or closed? strict < or ≤? Check each end of an interval answer.
  • Domain first: radicand ≥ 0, denominator ≠ 0, log argument > 0; square only non-negative sides.
  • Multiplying an inequality by a negative number flips it.
  • A ⇒ B with A false is true; the converse is a different statement.
  • Negating: swap ∀ ↔ ∃ and negate only the final condition.
  • Maps: name domain and codomain before deciding onto; one counterexample disproves injective.
  • Induction: base case written out, hypothesis used in the step.
  • Counting: does order matter? are repeats allowed? then pick the formula.
