Exercise 5.1: Polar coordinates

Convert with r = √x2 + y2 and pick φ from the quadrant; for regions, ask which radii and which angles occur.

Connected topic: Polar coordinates (§3.6).

1a: Polar coordinates of (−5, 4) and (2, √7)

Try first: compute r by Pythagoras, then decide each point’s quadrant before you use arctan.

Attempted it? Open the worked steps

1a · Polar coordinates of (−5, 4) and (2, √7)

  1. Convert with the rules of §3.6: r is the distance from the origin, and φ ∈ [0, 2π) is read from tan φ = yx together with the signs of x and y.

  2. (−5, 4): r = √25 + 16 = √41 ≈ 6.40. Here x < 0 and y > 0, so the point is in quadrant II and π must be added to the arctan value:

    φ = arctan(4−5) + π = π − arctan(45) ≈ 2.47

  3. (2, √7): r = √4 + 7 = √11 ≈ 3.32. Both coordinates are positive (quadrant I), so the arctan value is already the angle:

    φ = arctan(√72) ≈ 0.924

  4. Results: (−5, 4) = (√41, π − arctan 45) ≈ (6.40, 2.47) and (2, √7) = (√11, arctan √72) ≈ (3.32, 0.924).

    Check: 6.40 · cos 2.47 ≈ −5.0 and 6.40 · sin 2.47 ≈ 4.0. A common slip is to stop at arctan(−0.8) ≈ −0.67, which points into quadrant IV.

1b: Sketch the left half of the unit circle and write it in polar form

Try first: which radius do all points of x2 + y2 = 1 share, and which angles give x < 0?

Attempted it? Open the worked steps

1b · Sketch the left half of the unit circle and write it in polar form

  1. x2 + y2 = 1 is the unit circle, so every point of M has r = 1.

  2. On the unit circle x = cos φ, and cos φ < 0 exactly for π2 < φ < 3π2. The endpoints (0, ±1) have x = 0 and are excluded.

    M = {(r, φ) : r = 1, π2 < φ < 3π2}

  3. Check: φ = π gives (−1, 0), which has x < 0 and lies on the circle.

1c: Sketch the ray region M and the line ℓ, and write ℓ in polar form

Try first: the angles in M span exactly π, so M is bounded by one line through the origin. Then substitute x = r cos φ, y = r sin φ into y = −½x + 2 and solve for r.

Attempted it? Open the worked steps

1c · Sketch the ray region M and the line ℓ, and write ℓ in polar form

  1. The set M. M collects all rays from the origin with angles strictly between 0.85π and 1.85π, plus the origin itself (r = 0). The two boundary angles point in opposite directions along one line through the origin, and tan(0.85π) ≈ −½ says that line is y = −½x.

  2. The middle angle 1.35π points down and to the left, so M is the open half-plane below that line, together with the origin:

    M = {(x, y) : y < −½x} ∪ {(0, 0)}

  3. The line ℓ in polar form. Substitute x = r cos φ and y = r sin φ into y = −½x + 2:

    r sin φ = −½ r cos φ + 2 ⇔ r(2 sin φ + cos φ) = 4

    Wherever 2 sin φ + cos φ > 0 this gives

    r = f(φ) = 42 sin φ + cos φ

  4. Which rays meet ℓ? A radius must be positive, so a ray at angle φ meets ℓ exactly when 2 sin φ + cos φ > 0. The denominator vanishes when tan φ = −½, that is at φ ≈ 0.85π and φ ≈ 1.85π (exactly π − arctan ½ and its partner one half-turn later); between those angles it is negative.

    ℓ = {(r, φ) : r = 42 sin φ + cos φ, φ ∈ [0, 0.85π) ∪ (1.85π, 2π)}

  5. Check: φ = π2 gives r = 42 = 2, the point (0, 2), which lies on ℓ. Notice that 2 sin φ + cos φ ≤ 0 for every angle in M, so f is never positive there: no ray of M reaches ℓ, which fits the picture, since ℓ runs parallel to M’s boundary on the other side.

Exercise 5.2: Arithmetic rules

Turn powers into exponentials with xα = eα ln x, and combine logarithms with ln a + ln b = ln(ab).

Connected topic: Elementary functions (§3.5).

2a-i: Evaluate √e3 ln 4

Try first: write the square root as the power ½ and use eln 4 = 4.

Attempted it? Open the worked steps

2a-i · Evaluate √e3 ln 4

  1. A square root is the power ½, and powers of e multiply exponents:

    √e3 ln 4 = (e3 ln 4)1/2 = e(3/2) ln 4 = (eln 4)3/2 = 43/2

  2. 43/2 = (√4)3 = 23 = 8.

    Check: e3 ln 4 = 43 = 64, and √64 = 8.

2a-ii: Simplify the x-th root expression for x > 0

Try first: write the x-th root as the power 1x, expand (2 + x)2 − 4, then divide by ex.

Attempted it? Open the worked steps

2a-ii · Simplify the x-th root expression for x > 0

  1. The x-th root is the power 1x, so the numerator is e to the exponent (2 + x)2 − 4x.

  2. Expand: (2 + x)2 − 4 = x2 + 4x, and x2 + 4xx = x + 4 because x > 0.

  3. Dividing by ex subtracts x from the exponent:

    ex + 4ex = e4

    The answer does not depend on x. Check with x = 1: the root is e5, and e5 ÷ e = e4.

2b-i: Simplify ln(2x) + ln(2y) − ln z − ln 4

Try first: collect sums of logarithms into one product and differences into one quotient.

Attempted it? Open the worked steps

2b-i · Simplify ln(2x) + ln(2y) − ln z − ln 4

  1. For positive arguments ln a + ln b = ln(ab) and ln a − ln b = ln ab:

    ln(2x) + ln(2y) − ln z − ln 4 = ln 2x · 2y4z = ln xyz

  2. Check with x = y = z = 1: the left side is 2 ln 2 − 0 − ln 4 = 0 = ln 1.

2b-ii: Simplify ln(x2 − y2) − ln(2(x − y)) for x > y

Try first: factor x2 − y2 and say why both logarithms are defined.

Attempted it? Open the worked steps

2b-ii · Simplify ln(x2 − y2) − ln(2(x − y)) for x > y

  1. Since x > y > 0, both x − y and x + y are positive, so both arguments are positive and the rules apply.

  2. Factor the difference of squares and cancel x − y ≠ 0:

    ln(x2 − y2) − ln(2(x − y)) = ln (x − y)(x + y)2(x − y) = ln x + y2

  3. Check with x = 3, y = 1: ln 8 − ln 4 = ln 2 = ln 3 + 12.

Exercise 5.3: Complex numbers

For quotients multiply by the conjugate of the denominator; for powers switch to polar form.

Connected topics: Complex arithmetic and polar form (§4.1) and Roots and powers (§4.2).

3a: Real part, imaginary part and magnitude of 1 + i1 − i

Try first: multiply top and bottom by 1 + i.

Attempted it? Open the worked steps

3a · Real part, imaginary part and magnitude of 1 + i1 − i

  1. The denominator’s conjugate is 1 + i, and (1 − i)(1 + i) = 1 − i2 = 2:

    1 + i1 − i = (1 + i)22 = 1 + 2i + i22 = 2i2 = i

  2. So Re = 0, Im = 1 and |i| = 1.

    Check: |1 + i| = |1 − i| = √2, so the quotient must have magnitude 1.

3b: Real part, imaginary part and magnitude of (−√5 + i√5)3(1 + i)2

Try first: write both factors in exponential form; then lengths multiply and angles add.

Attempted it? Open the worked steps

3b · Real part, imaginary part and magnitude of (−√5 + i√5)3(1 + i)2

  1. −√5 + i√5 = √5(−1 + i). Its length is √5 · √2 = √10, and it lies in quadrant II at angle 3π4:

    −√5 + i√5 = √10 ei3π/4

  2. Cube it with de Moivre: the length becomes (√10)3 = 10√10 and the angle 3 · 3π4 = 9π4, which is π4 after removing a full turn.

  3. (1 + i)2 = 1 + 2i − 1 = 2i = 2eiπ/2. Multiply lengths and add angles:

    10√10 eiπ/4 · 2eiπ/2 = 20√10 ei3π/4 = 20√10(−√22 + i√22) = −20√5 + 20√5i

  4. So Re = −20√5 ≈ −44.7, Im = 20√5 ≈ 44.7, and the magnitude is 20√10 ≈ 63.2.

    Check: |−20√5 + 20√5i| = 20√5 · √2 = 20√10, matching the product of the lengths 10√10 · 2.

3c: Real part, imaginary part and magnitude of 2612 − 5i + 395 + 12i

Try first: both denominators have magnitude squared 169 = 132; use that to bring the sum over one denominator.

Attempted it? Open the worked steps

3c · Real part, imaginary part and magnitude of 2612 − 5i + 395 + 12i

  1. (12 − 5i)(12 + 5i) = 144 + 25 = 169 and (5 + 12i)(5 − 12i) = 25 + 144 = 169. Multiply each fraction by the conjugate of its denominator:

    2612 − 5i + 395 + 12i = 26(12 + 5i) + 39(5 − 12i)169

  2. Numerator: 312 + 130i + 195 − 468i = 507 − 338i. Since 507 = 3 · 169 and 338 = 2 · 169, the sum is 3 − 2i.

  3. So Re = 3, Im = −2 and |3 − 2i| = √9 + 4 = √13.

    Check: 2612 − 5i = 26(12 + 5i)169 = 24 + 10i13 and 395 + 12i = 39(5 − 12i)169 = 15 − 36i13; adding gives 39 − 26i13 = 3 − 2i.

Exercise 5.4: Complex polar coordinates

Read |z − a| as a distance, split z = x + iy when real and imaginary parts are compared, and keep z ≠ 0 when dividing by z.

Connected topic: Complex arithmetic and polar form (§4.1).

4i: Sketch {z ∈ ℂ : |z − i| = 3}

Try first: what does |z − a| measure in the Gaussian plane?

Attempted it? Open the worked steps

4i · Sketch {z ∈ ℂ : |z − i| = 3}

  1. |z − i| is the distance from z to the point i. The set of points at distance exactly 3 from i is a circle.

    {z : |z − i| = 3} = circle with centre i = (0, 1) and radius 3

  2. Check: 4i and −2i are both 3 away from i.

4ii: Sketch {z ∈ ℂ : |z| − z̅ = 1 + 2i}

Try first: write z = x + iy, so z̅ = x − iy, and compare real and imaginary parts.

Attempted it? Open the worked steps

4ii · Sketch {z ∈ ℂ : |z| − z̅ = 1 + 2i}

  1. With z = x + iy: |z| − z̅ = √x2 + y2 − x + iy. Comparing with 1 + 2i:

    y = 2 and √x2 + y2 − x = 1

  2. So √x2 + 4 = x + 1. A square root is never negative, so x + 1 ≥ 0. Squaring: x2 + 4 = x2 + 2x + 1, so 2x = 3 and x = 32, which satisfies x + 1 ≥ 0.

  3. The set is the single point z = 32 + 2i.

    Check: |32 + 2i| = √94 + 4 = 52, and 52 − (32 − 2i) = 1 + 2i.

4iii: Sketch {z ∈ ℂ : Re(1z) ≤ 2}

Try first: write 1z = z̅|z|2 and multiply the inequality by |z|2 > 0.

Attempted it? Open the worked steps

4iii · Sketch {z ∈ ℂ : Re(1z) ≤ 2}

  1. The set needs z ≠ 0. With z = x + iy, 1z = x − iyx2 + y2, so Re 1z = xx2 + y2.

  2. Multiply by x2 + y2 > 0 (the direction of ≤ stays) and complete the square:

    x ≤ 2(x2 + y2) ⇔ x2 − x2 + y2 ≥ 0 ⇔ (x − 14)2 + y2 ≥ 116

  3. So the set is everything on or outside the circle with centre 14 and radius 14, except the origin, which lies on that circle but is not allowed.

  4. Check: z = 14 is inside the disc and gives Re 1z = 4 > 2 (excluded); z = 1 gives 1 ≤ 2 (included).

Self-Study 5.5: Polynomial division and factorisation

Guess a root among the divisors of the constant term, divide by (x − root), and factor what is left.

Connected topics: Elementary functions (§3.5) and Complex polynomials (§4.3).

5a: Factorise x3 − 2x2 − x + 2

Try first: test x = 1 and x = −1.

Attempted it? Open the worked steps

5a · Factorise x3 − 2x2 − x + 2

  1. x = 1 gives 1 − 2 − 1 + 2 = 0, so (x − 1) is a factor.

  2. Divide: x3 − 2x2 − x + 2 = (x − 1)(x2 − x − 2). The quadratic has the roots 2 and −1 (product −2, sum 1).

    x3 − 2x2 − x + 2 = (x − 1)(x − 2)(x + 1)

  3. Check: (x − 2)(x + 1) = x2 − x − 2, and multiplying by x − 1 gives back the cubic. The product of the roots, 1 · 2 · (−1) = −2, equals minus the constant term, as it must for a monic cubic.

5b: Factorise x3 + x2 − 2

Try first: x = 1 is a root; after dividing, check the discriminant of the quadratic.

Attempted it? Open the worked steps

5b · Factorise x3 + x2 − 2

  1. x = 1 gives 1 + 1 − 2 = 0. Dividing: x3 + x2 − 2 = (x − 1)(x2 + 2x + 2).

  2. The quadratic has discriminant 4 − 8 = −4 < 0, so it has no real roots; its complex roots are −2 ± 2i2 = −1 ± i.

    x3 + x2 − 2 = (x − 1)(x2 + 2x + 2) = (x − 1)(x + 1 − i)(x + 1 + i)

  3. Check: (x − 1)(x2 + 2x + 2) = x3 + 2x2 + 2x − x2 − 2x − 2 = x3 + x2 − 2. Over ℝ the factorisation stops at the quadratic; the complex pair is conjugate, as for every real polynomial.

5c: Factorise x4 − 5x2 + 4

Try first: x = 1 and x = −1 are both roots; divide twice (or set u = x2).

Attempted it? Open the worked steps

5c · Factorise x4 − 5x2 + 4

  1. x = 1: 1 − 5 + 4 = 0. Dividing by x − 1 gives x3 + x2 − 4x − 4.

  2. x = −1 is a root of that cubic: −1 + 1 + 4 − 4 = 0. Dividing by x + 1 gives x2 − 4 = (x − 2)(x + 2).

    x4 − 5x2 + 4 = (x − 1)(x + 1)(x − 2)(x + 2)

  3. Check with u = x2: u2 − 5u + 4 = (u − 1)(u − 4), and u − 1 = (x − 1)(x + 1), u − 4 = (x − 2)(x + 2).

5d: Divide 2x3 + 3x2 − 5x + 1 by x2 + x − 1 with remainder

Try first: the first quotient term is 2x3x2 = 2x; subtract and repeat until the degree drops below 2.

Attempted it? Open the worked steps

5d · Divide 2x3 + 3x2 − 5x + 1 by x2 + x − 1 with remainder

  1. First term 2x: 2x(x2 + x − 1) = 2x3 + 2x2 − 2x. Subtracting leaves x2 − 3x + 1.

  2. Next term 1: x2 + x − 1. Subtracting leaves −4x + 2, whose degree is below 2, so the division stops.

    2x3 + 3x2 − 5x + 1 = (2x + 1)(x2 + x − 1) + (−4x + 2)

  3. Quotient 2x + 1, remainder −4x + 2. Check: (2x + 1)(x2 + x − 1) = 2x3 + 3x2 − x − 1, and adding −4x + 2 gives 2x3 + 3x2 − 5x + 1.

Self-Study 5.6: Roots of polynomials

Build the proof of Theorem 3.7 in four steps: degrees add, xk − x0k has the factor x − x0, so a root splits off a linear factor, and induction counts the roots.

Connected topics: Elementary functions (§3.5) and Mathematical induction (§2.5).

6a: Show deg(P · Q) = deg P + deg Q

Try first: which term of the product can have the highest power, and why is its coefficient not zero?

Attempted it? Open the worked steps

6a · Show deg(P · Q) = deg P + deg Q

  1. Multiplying out, every term of P · Q has the form aibjxi + j with i ≤ n and j ≤ k, so no power above xn + k appears.

  2. The power xn + k arises only from i = n, j = k, with coefficient anbk. In ℝ a product of two nonzero numbers is nonzero, so anbk ≠ 0.

    P(x)Q(x) = anbkxn + k + (lower powers), anbk ≠ 0

  3. Hence deg(P · Q) = n + k = deg P + deg Q. The step that matters is anbk ≠ 0: without it the top terms could cancel.

6b: Show xk − x0k = (x − x0) ∑j=0k−1 xk−1−jx0j

Try first: multiply out the right side and look for a telescoping sum.

Attempted it? Open the worked steps

6b · Show xk − x0k = (x − x0) ∑j=0k−1 xk−1−jx0j

  1. Multiply the sum by x and by −x0 separately:

    (x − x0)∑j=0k−1 xk−1−jx0j = ∑j=0k−1 xk−jx0j − ∑j=0k−1 xk−1−jx0j+1

  2. Shift the index in the second sum (j + 1 → j), so it runs over j = 1, …, k with terms xk−jx0j. All terms with j = 1, …, k − 1 cancel; only j = 0 from the first sum and j = k from the second remain:

    = xk − x0k

  3. Check with k = 2: (x − x0)(x + x0) = x2 − x02.

6c: Show P(x) = (x − x0)Q(x) with deg Q = n − 1

Try first: subtract P(x0) = 0 from P(x); the constant terms cancel, and each remaining difference xk − x0k has the factor from 6b.

Attempted it? Open the worked steps

6c · Show P(x) = (x − x0)Q(x) with deg Q = n − 1

  1. Since P(x0) = 0, P(x) = P(x) − P(x0). The constant a0 cancels:

    P(x) = ∑k=1n ak(xk − x0k)

  2. Apply 6b to every term and pull out the common factor:

    P(x) = (x − x0) ∑k=1n ak ∑j=0k−1 xk−1−jx0j =: (x − x0)Q(x)

  3. Q is a polynomial. Its highest power xn−1 comes only from k = n, j = 0, with coefficient an ≠ 0, so deg Q = n − 1 (consistent with 6a: 1 + (n − 1) = n).

6d: Prove Theorem 3.7 by induction on n

Try first: base case degree 1; in the step, if P has a root, split off x − x0 with 6c and apply the hypothesis to Q.

Attempted it? Open the worked steps

6d · Prove Theorem 3.7 by induction on n

  1. Claim A(n): every real polynomial of degree n has at most n real roots.

  2. Base case n = 1: a1x + a0 with a1 ≠ 0 has exactly one root, x = −a0a1.

  3. Induction step: assume A(n) and let P have degree n + 1. If P has no real root, there is nothing to show. Otherwise pick a root x0; by 6c, P(x) = (x − x0)Q(x) with deg Q = n.

  4. If P(x) = 0 then x − x0 = 0 or Q(x) = 0, because a product of real numbers is zero only when a factor is. So every root of P is x0 or a root of Q, and by A(n) Q has at most n real roots. Hence P has at most n + 1.

    Therefore A(n) holds for all n ∈ ℕ.

Self-Study 5.7: Difference formulas

Write x and y as a sum and a difference of the half-sum and half-difference, then apply the addition theorems.

Connected topic: Elementary functions (§3.5).

7a: Prove the difference formulas for sine and cosine

Try first: set a = x + y2 and b = x − y2, so that x = a + b and y = a − b.

Attempted it? Open the worked steps

7a · Prove the difference formulas for sine and cosine

  1. Let a = x + y2 and b = x − y2. Then x = a + b and y = a − b.

  2. Sine: by the addition theorems, sin(a + b) − sin(a − b) = (sin a cos b + cos a sin b) − (sin a cos b − cos a sin b) = 2 cos a sin b.

    sin x − sin y = 2 cos(x + y2) sin(x − y2)

  3. Cosine: cos(a + b) − cos(a − b) = (cos a cos b − sin a sin b) − (cos a cos b + sin a sin b) = −2 sin a sin b. Since sine is odd, −sin b = sin(−b) = sin y − x2:

    cos x − cos y = 2 sin(x + y2) sin(y − x2)

  4. Check with x = π2, y = 0: sin π2 − 0 = 1, and 2 cos π4 sin π4 = 2 · √22 · √22 = 1.

7b: Show sin x − sin(x − π3) = cos(x − π6) and cos x − cos(x + π3) = sin(x + π6)

Try first: put y = x − π3 (then y = x + π3) into 7a and use sin π6 = ½.

Attempted it? Open the worked steps

7b · Show sin x − sin(x − π3) = cos(x − π6) and cos x − cos(x + π3) = sin(x + π6)

  1. With y = x − π3: x + y2 = x − π6 and x − y2 = π6. So sin x − sin(x − π3) = 2 cos(x − π6) sin π6 = 2 · ½ · cos(x − π6) = cos(x − π6).

  2. With y = x + π3: x + y2 = x + π6 and y − x2 = π6. So cos x − cos(x + π3) = 2 sin(x + π6) sin π6 = sin(x + π6).

    Check with x = 0: 0 − sin(−π3) = √32 = cos(−π6), and 1 − cos π3 = ½ = sin π6.

7c-i: Solve sin x − sin(x − π3) = ½ for x ∈ [π, 2π]

Try first: by 7b the equation is cos(x − π6) = ½; work out the range of t = x − π6.

Attempted it? Open the worked steps

7c-i · Solve sin x − sin(x − π3) = ½ for x ∈ [π, 2π]

  1. By 7b the equation reads cos t = ½ with t = x − π6. For x ∈ [π, 2π], t runs through [5π6, 11π6].

  2. arccos ½ = π3, but π3 is not in that range. Using cos t = cos(2π − t), the other angle with cosine ½ is 2π − π3 = 5π3, which is in the range.

  3. So t = 5π3 and x = 5π3 + π6 = 11π6. No other angle in [5π6, 11π6] has cosine ½.

    Check: sin 11π6 − sin 3π2 = −½ − (−1) = ½.

7c-ii: Solve cos x − cos(x + π3) = −√22 for x ∈ [π2, 3π2]

Try first: by 7b the equation is sin(x + π6) = −√22; find the range of t = x + π6.

Attempted it? Open the worked steps

7c-ii · Solve cos x − cos(x + π3) = −√22 for x ∈ [π2, 3π2]

  1. By 7b the equation reads sin t = −√22 with t = x + π6. For x ∈ [π2, 3π2], t runs through [2π3, 5π3].

  2. arcsin(−√22) = −π4, which is not in that range. Using sin t = sin(π − t), the angle π − (−π4) = 5π4 also has sine −√22, and it is in the range. The next candidate, 7π4, is above 5π3.

  3. So t = 5π4 and x = 5π4 − π6 = 13π12.

    Check numerically: cos(13π12) − cos(17π12) ≈ −0.966 − (−0.259) = −0.707 ≈ −√22.

12b · Factorise P into linear factors

  1. Divide by t − ½: 4t3 − 3t + 1 = (t − ½)(4t2 + 2t − 2). Check: (t − ½)(4t2 + 2t − 2) = 4t3 + 2t2 − 2t − 2t2 − t + 1.

  2. 4t2 + 2t − 2 = 2(2t2 + t − 1) = 2(2t − 1)(t + 1). Together:

12c · Find all x ∈ [0, 2π) with cos(3x) = −1 and explain the double root

  1. cos(3x) = −1 ⇔ 3x = π + 2kπ ⇔ x = π + 2kπ3. In [0, 2π) this gives x = π3, π, 5π3.

  2. Their cosines are cos π3 = ½, cos π = −1 and cos 5π3 = ½: the three solutions give only the two roots ½ and −1 of P.

Self-Study 5.13: Periodicity

To show T is a period, compute f(x + T). To show it is the smallest, find all x with f(x) = f(0) and use that every period lies among them.

Connected topic: Elementary functions (§3.5).

13a: If g has period T, then g(kx) has period Tk

Try first: compute h(x + Tk).

Attempted it? Open the worked steps

13a · If g has period T, then g(kx) has period Tk

  1. h(x + Tk) = g(k(x + Tk)) = g(kx + T) = g(kx) = h(x), so Tk is a period of h.

  2. Sine and cosine have period 2π, so sin(kx) and cos(kx) have period 2πk.

    Check: sin(2x) repeats after π, as its graph shows.

  1. f(−x) = cos(−2x) + cos(−3x) = cos(2x) + cos(3x) = f(x), because cosine is even.

13b-ii: 2π is a period of f

Try first: compute f(x + 2π) term by term.

Attempted it? Open the worked steps

13b-ii · 2π is a period of f

  1. cos(2(x + 2π)) = cos(2x + 4π) = cos(2x) and cos(3(x + 2π)) = cos(3x + 6π) = cos(3x), since 4π and 6π are whole turns. So f(x + 2π) = f(x).

13b-iii: 2π is the smallest period of f

Try first: f(0) = 2 and each cosine is at most 1; when is f(x) = 2?

Attempted it? Open the worked steps

13b-iii · 2π is the smallest period of f

  1. Each cosine is at most 1, so f(x) = 2 exactly when cos(2x) = 1 and cos(3x) = 1, that is 2x ∈ 2πℤ and 3x ∈ 2πℤ: x ∈ πℤ and x ∈ 2π3ℤ.

  2. A number in both is a multiple of π and of 2π3; then x = 3x − 2x is a difference of multiples of 2π, so x ∈ 2πℤ. Conversely every multiple of 2π works.

  3. If T > 0 is a period, f(T) = f(0) = 2, so T ∈ 2πℤ and T ≥ 2π. Hence 2π is the smallest period.

13c: g(x) = sin(4x) + sin(6x) is odd with period π

Try first: use sin(−u) = −sin u, then compute g(x + π).

Attempted it? Open the worked steps

13c · g(x) = sin(4x) + sin(6x) is odd with period π

  1. g(−x) = sin(−4x) + sin(−6x) = −sin(4x) − sin(6x) = −g(x), so g is odd.

  2. g(x + π) = sin(4x + 4π) + sin(6x + 6π) = sin(4x) + sin(6x) = g(x), so π is a period (by 13a, sin(4x) has period π2 and sin(6x) period π3, and π is a multiple of both).

Attempted it? Open the worked steps

13d · cos(mx) + cos(nx) has smallest period 2πgcd(m, n)

  1. Write m = m̃k, n = ñk with gcd(m̃, ñ) = 1. Period: m · 2πk = 2πm̃ and n · 2πk = 2πñ are whole turns, so f(x + 2πk) = f(x).

  2. Smallest: f(x) = 2 = f(0) exactly when mx ∈ 2πℤ and nx ∈ 2πℤ. Put s = kx2π. The conditions say m̃s ∈ ℤ and ñs ∈ ℤ.

  3. Because gcd(m̃, ñ) = 1 there are integers u, v with um̃ + vñ = 1 (Bézout). Then s = u(m̃s) + v(ñs) ∈ ℤ. Conversely every integer s works. So f(x) = 2 exactly for x ∈ 2πkℤ.

  4. Any period T > 0 satisfies f(T) = f(0) = 2, so T is a positive multiple of 2πk. The smallest period is 2πk.

    Check with 13b: m = 2, n = 3, gcd 1, period 2π.

13e: h(x) = sin x + sin(3x): h(x + π) = −h(x), so 2π is a period and π is not

Try first: sin(u + π) = −sin u and 3π = π + 2π.

Attempted it? Open the worked steps

13e · h(x) = sin x + sin(3x): h(x + π) = −h(x), so 2π is a period and π is not

  1. h(x + π) = sin(x + π) + sin(3x + 3π) = −sin x − sin(3x) = −h(x), because adding π (or 3π) flips the sign of sine.

  2. Apply it twice: h(x + 2π) = −h(x + π) = h(x), so 2π is a period.

  3. π is not a period: that would need h(x + π) = h(x), i.e. −h(x) = h(x), i.e. h(x) = 0 for every x. But h(π6) = ½ + 1 = 32 ≠ 0.

14b · When is ln(x + y) = ln x + ln y true?

  1. By 14a-i the claim reads ln(x + y) = ln(xy). The logarithm is injective (strictly increasing), so this holds exactly when x + y = xy.

  2. Solve for y: y(x − 1) = x. For x = 1 this says 0 = 1, impossible. Otherwise y = xx − 1, and y > 0 requires x > 1.

    ln(x + y) = ln x + ln y ⇔ y = xx − 1 with x > 1 ⇔ (x − 1)(y − 1) = 1, x, y > 1

  3. So the student is right only on that hyperbola, for example (2, 2): ln 4 = ln 2 + ln 2. Check (3, 32): x + y = xy = 92.
